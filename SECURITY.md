# Security Policy

## Supported Versions

Security updates, bug fixes, and patches are actively applied to the main branch and current production releases of Minigame Tech.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Minigame Tech and its users seriously. If you discover a security vulnerability, performance issue, or unexpected behavior within the web platform or the Android application, please report it responsibly.

### How to Report

* **Primary Contact:** Please send an email directly to [codelab.italia@gmail.com](mailto:codelab.italia@gmail.com).
* **Details to Include:** To help us understand and reproduce the issue efficiently, please provide:
  * A clear description of the vulnerability.
  * Steps or a proof-of-concept to reproduce the issue.
  * The environment affected (e.g., specific browser, Android version, or device).

### What to Expect

* **Acknowledgment:** You will receive an initial response acknowledging receipt of your report within 48–72 hours.
* **Updates:** We will keep you informed regarding the progress of the investigation, validation, and remediation of the vulnerability.
* **Disclosure:** Once the issue is patched and a secure update is deployed (both on GitHub Pages and via the Google Play Store update if applicable), public disclosure or credit can be coordinated responsibly.

Thank you for helping keep Minigame Tech safe, secure, and running smoothly!
